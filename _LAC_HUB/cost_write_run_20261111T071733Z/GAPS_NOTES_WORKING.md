# Working notes for GAPS (assembled into the GAPS file at the end)

- Setup: `py` on this machine is Python 3.12.0 from python.org (Python312), not Anaconda. It has openpyxl 3.1.5, pandas 3.0.2 and pywin32. Used as is.
- A4: `py -I -m unittest test_ao_cost_repair_manager -v` fails with ModuleNotFoundError because `-I` implies `-P` (the current folder is not put on sys.path). The same four tests were run with `py -I -m unittest discover -s . -t . -p test_ao_cost_repair_manager.py -v`: 4 of 4 OK. Both logs are kept.
- B1 interpreter: the pipeline scripts were run with Anaconda Python 3.12.4 (pandas 2.2.2), the interpreter the brief names; `py` (python.org 3.12.0, pandas 3.0.2) cannot run the DR compiler (pandas 3 string dtype) or the Guatemala compiler. My own scripts ran with `py -I`.
- Guatemala A2 compiler uses DataFrame.append and ExcelWriter.save, removed in pandas 2.0; no local environment has pandas 1.x. It was run unchanged through scripts/run_with_append_shim.py, which restores those two methods with the pandas 1.5 logic (concat). Result reproduces the tracked BAU, NDCNEW and LTSNEW keyed with 0 differences, so the shim is accepted as the canonical runner. No pipeline script was edited.
- A2 compilers write BAU plus folders named after older scenarios (NDCincond/NDCcond for CR and DR, NDCINC for Ecuador, NDP for Guatemala and Honduras; Jamaica writes LTSNEW directly). The tracked NDCNEW and LTSNEW folders are the existing folders with the compiler's produced files of one such folder copied over them (Scenario column keeps the compiler label). Chosen per country by fewest keyed differences: CR from BAU, DR from NDCcond, Ecuador from BAU, Guatemala from NDP, Honduras from NDP, Jamaica from LTSNEW. The compilers' missing output folders were created empty for the run and removed after. The A2 run also rewrites A1_Outputs/*_COMPLETED.xlsx, pickles, A2_Structure_Lists.xlsx (and Guatemala A2_Extra_Inputs/A-Xtra_Projections_COMPLETED.csv, untracked); these are restored with git checkout after every run so the diff stays inside the scope of F1.
- Costa Rica B1_Scenario_Config.xlsx activates a fourth scenario LTSOPT with no A2_Output_Params/LTSOPT, so B1 stops at once. Without editing the config: a temporary A2_Output_Params/LTSOPT (copy of LTSNEW) and an empty B1_Output_Params/LTSOPT are created for the run and removed after, with Executables/LTSOPT_0. BAU, NDCNEW and LTSNEW then reproduce exactly.
- B1 solve status and objective: scripts/glpsol_wrap/glpsol.bat is put first on PATH for the B1 runs only; it calls the real glpsol.exe with B1's own arguments and logs the Status and Objective lines of the -o file before B1 parses and deletes it. Exit code passed through unchanged. First CR attempt failed because the log path was relative (wrapper exit 1 after an OPTIMAL solve); fixed and re-run.
- SelectedResults.csv written by B1 in model folders: untracked copies deleted; Ecuador's tracked copy restored with git checkout (brief: ignore, last writer wins).
- D3 reading (CR): the source job states the workbook convention, 2021 column in 2021 USD and 2022 to 2050 in 2022 USD (LAC_COST_SRC_CR REPORT line 58, GAPS item 11), so CR groups are converted per column (2021 by CPI 2024/2021, 2022 to 2050 by CPI 2024/2022). The brief's single factor per group would leave the 2021 column in mixed units.
- D3 reading (per row): the currency year is taken per row (value-adjacent statement, then the clause the value comes from, then one stated year among the row's source entries), so a group can mix converted and left rows (Honduras keep rows 2018 to 2023 from PIEG 2024-2033 Tabla 7, upgrade rows 2024 to 2050 from PIEG 2026-2035 in 2024 USD).
- D3 overrides (explicit): Guatemala PPHDAM FixedCost left (value from PEIG 2026-2050, NAT-001, currency year not stated; IRENA only a range check); Guatemala PPPVDS inherits PPPVD's per-year year (unitless ATB ratio); Jamaica PPPVDS and PPWNDONS CapitalCost and FixedCost left (mixed currency years); Jamaica PPBGS and PPBIM VariableCost: keep rows from IRENA 2022 (2022 USD), upgrade rows from IRENA 2025 (2025 USD, left: D3 covers only years before 2024).
- D3 years after 2024 (2025 USD, Jamaica PPGEO FixedCost and the IRENA 2025 rows) are left: the rule covers years before 2024. Jamaica PPNGS CapitalCost (January 2010 prices) is left: no CPI-U 2010 in any constants.csv.
- D8 reading: "written values vary by year" is read as the row as it stands after the write (written cells plus cells left as they are), because A2's Flat mode copies the first year column to every year; e.g. Honduras PPHDAM FixedCost gets 37.93 written for 2024 to 2050 while 2018 to 2023 keep 47.06, which Flat would ignore.
- D7 scope from the review pack REPORT (Gas conversion): the F5 sentence on 105 Jamaica DIST_NGS rows and 81 DR DIST_NGS projected rows, whose values were not divided by 0.9 (LNG import CIF per tonne / IPCC NCV, already net).
- D8 fill: 14 rows switched from Flat to User defined (Honduras thermal and hydro FixedCost/VariableCost, Ecuador PPPVT and PPWNDON CapitalCost) had empty year cells that were not written (keep rows). Flat filled them from the first year column; under User defined they would compile as missing. The 63 empty cells get their keep proposal value (equal, after A2's 4-decimal rounding, to what Flat produced), so the compiled values for those years do not change. This writes keep rows the D3 rule did not change, against the letter of C1, to honour D8 without changing the model in those years.
- C4(2) strict failure, not fixed (out of scope): five formula cells outside the manifest changed value when Excel recalculated, because they reference written cells through the workbook's own formulas: Guatemala Primary Techs I284:J284 (DIST_FLEXFUEL VariableCost 2018 and 2019 = DIST_GSL x 1.8; 47.11 to 45.31 and 41.05 to 40.11) and Honduras Secondary Techs I27:K27 (PPBGS CapitalCost 2018 to 2020 = PPBIM x 5053/5391; 5053 to 1813.8 after the regional PPBIM value). Neither row has proposals. One formula's text was normalised by Excel on save (DR Secondary Techs J232, ELE_TRANS CapitalCost 2018: the space after "=" removed; value unchanged). Known-limitation candidates.
